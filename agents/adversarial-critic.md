# Agent: adversarial critic

**Charter.** Argue against the product. Write the strongest possible "why this
should not be built" section and define the evidence that would change the
verdict. Also grill the design tree until the frontier is empty.

**Inputs.** The selected direction, the prior-art report, the star target.

**Deliverable.** `docs/research/adoption_grill_agent_report.md`: 12 failure
modes with mitigations, positioning, a 90-day plan with independent go/no-go
gates, and the negative case.

**Acceptance gate.** Must contain a genuine falsifiable claim with numeric
thresholds; must state plainly that a star count cannot be guaranteed; must
separate validity, safety, adoption and operational gates; must not rescue a
failed validity gate with good distribution. Rejected if it reads like
marketing, or refuses to say what would kill the project.

**Manager note.** The first run returned no usable sources and honestly refused
to fabricate. The manager rejected the empty result and re-tasked this agent
with a narrower, source-bounded brief rather than accepting a hollow report.
