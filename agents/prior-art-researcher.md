# Agent: prior-art researcher

**Charter.** Try to kill each candidate with located evidence. Survey link
checkers, doctest/example runners, embedded-code sync, workflow and schema
validators, architecture enforcement, repository packers, documentation-drift
tools, context-file linters, convention miners, false-green detectors, run
replay/receipts and environment-diff tools.

**Inputs.** Candidate directions from the product strategist.

**Deliverable.** `docs/research/prior_art_agent_report.md`: a table of tools,
repository links, exact checks, and exact non-goals; an explicit integrated
verdict; the strongest skeptical case; ranked design requirements.

**Acceptance gate.** Each tool states what it does NOT cover. Verdict is
conditional ("no single surveyed tool delivers the full integrated scope"),
never "nothing exists". Search boundaries and source quality are disclosed.
Approximate star counts are labelled as captures, not measurements.
Rejected if any repo link or capability is invented.

**Result.** Killed candidates A, B and C; narrowed the defensible claim.
